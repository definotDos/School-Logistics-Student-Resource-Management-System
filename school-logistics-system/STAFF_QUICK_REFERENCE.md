# Staff Dashboard - Quick Reference Guide

## 🎯 Common Workflows

### 1. Processing a New Request (Complete Workflow)

**Step 1: Review the Request**
```
Path: Dashboard → Review Requests
Action: Click "Review" on any pending request
View: Student info, resource type, eligibility status
```

**Step 2: Verify Eligibility**
```
Path: Verify Eligibility → Find Student
Action: Check eligibility status (Eligible/Not Eligible)
Decision: Proceed to approval or reject
```

**Step 3: Approve or Reject**
```
Path: Approve/Reject → Select Request
Action: Click "Approve" or "Reject"
Note: Reasons are automatically logged
```

**Step 4: Schedule Claim Window**
```
Path: Manage Schedules → Create Schedule
Details: Date, Time, Campus, Location
Students: Assign approved students to window
```

**Step 5: Update Status**
```
Path: Update Status → Find Request
Change: Pending → Approved → Ready for Claim → Released
Note: Student receives notification at each stage
```

**Step 6: Verify Claim**
```
Path: Verify Claims → Find Claim
Action: Verify student identity
Mark: Mark as "Complete" when resource is given
```

**Step 7: Monitor & Complete**
```
Path: Monitor Distribution → Track Status
View: Released vs Pending items
Note: Generate report when distribution is complete
```

---

### 2. Handling a Rejected Request

```
Review Requests → Find Problematic Request
↓
Send Notification with reason
↓
Student Reviews Feedback
↓
Student Resubmits (if eligible after fixing issue)
↓
Restart Workflow
```

---

### 3. Rescheduling a No-Show

```
Verify Claims → Find "No-Show" Claim
↓
Click "Reschedule"
↓
Assign to Different Claim Window
↓
Send Notification with New Schedule
↓
Monitor New Claim Date
```

---

### 4. Generating Weekly Reports

```
Dashboard → Click "Export weekly report"
or
Reports → Select "Request Summary Report"
↓
Customize: Date range, Campus, Resource type
↓
Generate → Download PDF/Excel
```

### Common Questions

**Q: How do I approve multiple requests at once?**
A: Use the Approve/Reject panel and filter by status, then approve each one.

**Q: Can students resubmit after rejection?**
A: Yes, they can resubmit in the Student Portal after addressing issues.

**Q: How do I track distribution progress?**
A: Monitor Distribution → See Released vs Pending items in real-time.

**Q: Where do I see student history?**
A: Student History → Search student name → Click "View History"

**Q: How do I send reminder notifications?**
A: Notifications → Click "Send" on Draft notifications

## 💡 Best Practices

### Request Processing
✓ Always verify student eligibility before approval
✓ Provide clear reason for rejections
✓ Process requests in order (FIFO)
✓ Update status immediately
✓ Send notifications at each stage

### Claim Management
✓ Schedule claims with adequate capacity (not too many students per time)
✓ Notify students at least 2 days before schedule
✓ Verify student ID at pickup
✓ Handle no-shows promptly
✓ Keep accurate records

### Distribution
✓ Monitor distribution progress daily
✓ Track pending items
✓ Communicate delays to students
✓ Reconcile counts at end of distribution

### Communication
✓ Use professional language in all communications
✓ Be clear and specific in notifications
✓ Include action items (what students need to do)
✓ Respond to student queries within 48 hours

## 🚨 Troubleshooting

### Issue: Can't find a request
**Solution**: Check filters, search by student name or request ID

### Issue: Student showing "Not Eligible"
**Solution**: Review eligibility criteria, consider if exception needed

### Issue: Can't send notification
**Solution**: Ensure recipients are selected, check internet connection

### Issue: Distribution shows "Pending"
**Solution**: Check if all students have claimed, release remaining stock

### Issue: Dashboard not updating
**Solution**: Refresh page (F5), clear cache, logout and login again
